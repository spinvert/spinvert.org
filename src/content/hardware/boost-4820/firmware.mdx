[Libre Solar charge controller firmware](https://github.com/LibreSolar/charge-controller-firmware),

ThingSet protocol.

## Control concept

The firmware controls the generator current according to a lookup curve, as derived in
[Optimal operation](/theory/optimal-operation/). In every control cycle, it performs the following
steps:

1. **Measure the frequency** of the AC generator voltage.
2. **Calculate the speed** from the frequency and the configured pole count:
   $n = 2 f_e / p$, i.e. $n = 2 \cdot 60\ \text{s/min} \cdot f_e / p$ in rpm.
3. **Look up the target current** for this speed. Between the points of the curve, the value is
   interpolated linearly.
4. **Control the boost converter** such that its input current matches the target current. The
   current is limited further if the output current or other limits are reached.

The resulting closed loop is stable without any knowledge of the wind speed: if the rotor is
faster than optimal, the target current is higher than the current the rotor can sustain, so it
slows down, and vice versa. The rotor inertia acts as a natural filter for gusts.

Using the frequency instead of the rectified voltage as input of the curve has an important
advantage: the voltage depends on the current because of the voltage drops in the generator,
while the frequency is an exact measure of the speed.

## Operating modes

The board switches between the following modes:

| Mode      | Condition                                            | Action                                                          |
| --------- | ---------------------------------------------------- | --------------------------------------------------------------- |
| Standby   | Generator speed too low to deliver power             | No load on the generator, so that the rotor can start up        |
| Boost     | Rectified voltage below battery voltage              | Boost converter tracks the lookup curve                         |
| Bypass    | Rectified voltage reaches battery voltage            | Boost converter idle, bypass diode conducts automatically       |
| Dump load | Battery full, overspeed or current above rating      | Generator loaded by the dump load to limit speed and voltage    |

## Battery charging

The battery is charged according to the charging algorithm of the Libre Solar firmware. When
the battery is full, the charge current has to be reduced. For a wind turbine, simply reducing
the current is not an option, as the rotor would accelerate. Instead, the excess power is diverted
to the dump load.

## Configuration and monitoring

The configuration parameters of the generator and the lookup curve are planned to be accessible
via the ThingSet protocol over USB or CAN-FD. The same interfaces provide live data such as
generator frequency, voltages, currents and operating mode.

The lookup curve can be calculated with the
[calculator](/hardware/boost-4820/operating-curve/#calculator), which exports the curve as CSV or JSON.
